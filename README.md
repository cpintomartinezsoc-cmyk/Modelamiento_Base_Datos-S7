Descripción general del sistema

Este repositorio contiene la implementación en lenguaje SQL de la base de datos para la plataforma que gestiona el capital humano del Holding Carpenter SPA. El sistema administra el personal de las distintas compañías del holding, junto con la información asociada a cada persona (comuna, región, género, estado civil, títulos e idiomas).

Contenido del Repositorio
Encargo_Semanal_S7.SQL: Script DDL y DML que contiene el borrado previo de objetos, la creación de las tablas del modelo relacional con sus restricciones (PK, FK, UN, CK), la definición de restricciones adicionales mediante ALTER TABLE, la creación de secuencias e identificadores autoincrementales, el poblamiento de las tablas IDIOMA, COMUNA, COMPANIA y REGION, y las consultas SQL para la generación de los informes solicitados por el Departamento de Gestión del Personal.
